## O que é o projeto

Um app de organização de tarefas pro dia a dia — diárias, semanais e anuais — com timer **Pomodoro** embutido, inspirado no **Notion**. Ideia de 3 colegas de faculdade (8° período), com a matéria de DevOps como motivação pra estruturar o projeto direito desde o começo.

> [!tip] Fluxo de trabalho do grupo
> pensar → documentar → desenvolver.
> Toda definição relevante é discutida, registrada na base de [[🗳️ Decisões]], e só depois implementada. Assim o código e a documentação andam sempre juntos.

## Objetivo central

Rodar em **multiplataforma** mantendo o produto sempre atualizado nas várias plataformas:

- **Web** — página acessível de qualquer navegador
- **Desktop** — executável instalável (Windows/Mac/Linux)
- **Mobile** — app (ainda não implementado, ver [[Projetos/TasksOrg - DevOps/✅ Próximos Passos]])

## Fase atual

Uma **POC (prova de conceito)** focada em validar a arquitetura multiplataforma e configurar o ferramental de DevOps (monorepo, CI/CD, containers) antes de partir pro desenvolvimento das features completas do produto.
